Connect the shared Google Sheet

  1. Open a blank Google Sheet, then Extensions > Apps Script.
  2. Paste the provided Code.gs file, save, and run setupOnce() one time.
  3. Deploy as Web app: Execute as Me, access Anyone.
  4. Copy the /exec URL, and paste it into the APPS_SCRIPT_URL setting near the top of GitHub index.html.
  5. Commit the updated index.html. Everyone shares the same connection automatically.

Do not paste index.html into Apps Script. Do not use the old Apps Script snippet from Gemini: it is incompatible with this page.
